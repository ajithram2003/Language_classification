## 📌 Overview

This project demonstrates **Natural Language Processing (NLP) and supervised machine learning** for identifying the language of a given text sample. It uses the Language Detection dataset and a **Multinomial Naive Bayes** classifier after converting text into numerical features.

## 🎯 Objectives

- Preprocess raw text for machine learning.
- Convert text into a bag-of-words representation.
- Train a Multinomial Naive Bayes classifier.
- Predict the language of unseen text.
- Explore language classification as an NLP problem.

## 🧠 Workflow

```text
Text Dataset
    ↓
Text Cleaning / Preprocessing
    ↓
Feature Extraction
    ↓
Bag-of-Words Representation
    ↓
Multinomial Naive Bayes
    ↓
Language Prediction
```

```bash

```

Open `Language classifiaction.ipynb` and run the cells in order.

## 📊 Dataset

The repository includes `Language Detection.csv`, which contains text samples and their corresponding language labels. The notebook uses this dataset for model development and evaluation.

## 📈 Evaluation

The notebook contains the model training and evaluation workflow. Performance should be interpreted using the metrics generated by the notebook rather than unsupported fixed values in this README.
